# Daily Shadowing 🎧

毎朝、シャドーイングにちょうどいい約10分の英語Vlogが1本届くアプリです。
動画を選ぶのはAI（Claude）に任せて、自分は練習するだけ。毎日の英語学習を続けやすくするために作りました。

## このアプリを作った理由

英語のスピーキング力を伸ばすために、海外のVlogを使ったシャドーイングを毎日やりたいと思っていました。でも、続けるうえで2つの壁がありました。

### 1. ちょうどいい長さの動画を探すのが大変

シャドーイングに向いているのは、10分前後で、ネイティブがカメラに向かって自然なスピードで話している動画です。
ところがYouTubeで探すと、長すぎたり、BGMばかりでほとんど話していなかったりする動画も多く、条件に合う1本を見つけるだけで時間がかかってしまいます。
練習を始める前に疲れてしまい、それが続かない原因になっていました。

### 2. 自分の好きな分野ばかりに偏ってしまう

自分で動画を選ぶと、どうしても興味のあるジャンルや見慣れたチャンネルばかりになります。
その結果、出会う単語や表現、聞き慣れるアクセントの幅が狭くなってしまいます。
実際の会話では、仕事の話も、旅行の話も、料理の話も出てきます。いろいろな場面の英語に触れられるようにしたいと思いました。

### そこで

「動画探し」をなくして、毎日違うジャンル・違うアクセントの動画が自動で届く仕組みを作りました。
アプリを開けば、その日に練習する動画がもう用意されています。

## 主な機能

- **毎朝のおすすめ動画**：毎朝6:47（シドニー時間）に、約8〜15分の英語Vlogが1本追加されます。
- **曜日ごとにジャンルとアクセントが変わる**：偏りがないように、ジャンル（仕事・日常・料理・旅行）と英語のアクセント（アメリカ・イギリス・オーストラリア）を曜日でローテーションします。
- **注目フレーズと練習のコツ**：動画ごとに、覚えておきたい日常表現3つ（意味つき）と、その日の練習のポイントが付きます。
- **練習記録と連続日数**：練習したらボタンをタップ。何日続いているかが表示されます。記録はデータベースに保存されるので、スマホとパソコンで共有できます。
- **過去の動画の一覧**：これまでの動画をいつでも見返せます。同じ動画が二度紹介されることはありません。
- **合言葉ロック**：合言葉を知っている人だけが使えます。

### 曜日ごとのテーマ

| 曜日 | ジャンル | アクセント |
|---|---|---|
| 月 | 仕事・キャリア | アメリカ英語 |
| 火 | 日常・ルーティン | イギリス英語 |
| 水 | 料理・カフェ | オーストラリア英語 |
| 木 | 旅行 | アメリカ英語 |
| 金 | 日常・ルーティン | オーストラリア英語 |
| 土 | 旅行 | イギリス英語 |
| 日 | 料理・カフェ または 仕事・キャリア | 自由 |

## しくみ

```
Claude（毎朝のスケジュールタスク）
  └─ 条件に合うVlogを探して data/videos.json に追加 → GitHubにpush
        └─ Vercelが自動で再デプロイ
              └─ アプリを開くと videos.json の内容がNeonに同期され、画面に表示
                    └─ 「練習した」の記録はNeonに保存
```

## 使っている技術

- **フロントエンド**：HTML / CSS / JavaScript（フレームワークなし、`public/index.html`）
- **API**：Vercel Serverless Functions（Node.js）
- **データベース**：Neon（サーバーレスPostgres）
- **動画の選定**：Claudeのスケジュールタスク（Web検索で条件に合う動画を探し、実在と長さを確認）

## ファイル構成

```
public/index.html      画面（今日の動画・履歴・連続日数・合言葉ロック）
api/videos.js          GET  /api/videos   動画一覧と練習記録
api/practice.js        POST /api/practice 練習記録を保存
api/_lib.js            Neon接続・テーブル自動作成・videos.json → Neon の同期・合言葉チェック
data/videos.json       毎朝追加される動画データ
```

テーブル（`videos`, `practice`）は初回アクセス時に自動で作られます。SQLを手で実行する必要はありません。

## セットアップ（Vercel + Neon）

1. **Vercelにリポジトリを追加**：Vercel → Add New → Project → `daily-shadowing` を Import。Framework Preset は「Other」のままで Deploy。
2. **Neonを連携**：プロジェクトの Storage タブ → Create Database → **Neon** → 無料プランで作成し、このプロジェクトに Connect。`DATABASE_URL` が自動で追加されます。
3. **合言葉を設定**：Settings → Environment Variables → Key に `APP_PASSCODE`、Value に好きな合言葉を入れて Save。
4. **再デプロイ**：Deployments → 最新のデプロイの「…」→ Redeploy（環境変数を反映するため）。
5. 発行されたURLを開いて合言葉を入力。スマホでは「ホーム画面に追加」するとアプリのように使えます。

## 動画データの形式（`data/videos.json`）

新しい日付のデータを配列に追加します（同じ日付があれば上書きされます）。

```json
{
  "date": "2026-11-07",
  "weekday": "土",
  "theme": "旅行",
  "accent": "イギリス英語",
  "title": "動画タイトル",
  "channel": "チャンネル名",
  "url": "https://www.youtube.com/watch?v=XXXXXXXXXXX",
  "duration": "約10分",
  "reason": "おすすめ理由",
  "phrases": [{ "en": "phrase", "ja": "意味" }],
  "tip": "練習のコツ"
}
```

## おすすめの練習方法

1. まず字幕ありで動画を1回通して聞く
2. 話している場面を2〜3分選び、字幕なしで少し遅れて声に出してついていく（シャドーイング）
3. 注目フレーズを自分の状況に置き換えて言ってみる
4. 余裕があれば自分の声を録音して、元の音声と比べる
